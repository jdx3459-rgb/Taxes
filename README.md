# 私人德州扑克房间

一个只有单一牌桌的网页版德州扑克小游戏。好友用相同的入口密码和昵称进入；入座玩家可参与牌局，其他人可以实时观战。

## 本地运行

```bash
cp .env.example .env
# 编辑 .env，设置一个私密的 ROOM_PASSWORD
npm install
npm start
```

打开 `http://localhost:3000`。部署时在托管平台的环境变量中设置 `ROOM_PASSWORD` 和（按平台要求）`PORT`，不要提交 `.env`。

## 规则与操作

- 一张桌子、最多 6 位入座玩家、观战人数不限。
- 每位入座玩家先获得 1,000 初始筹码并自动准备；两位玩家入座后会自动开局。
- 牌局进行时加入的玩家可提前准备并观战，本手结束后自动加入下一局。
- 支持弃牌、过牌、跟注、加注、全下，并可在不参与当前手牌时补充 500 或 1,000 筹码。
- 摊牌后自动评定七张牌中的最佳五张组合并分池；不足两人时会自动结束牌局。

这是休闲游戏，不涉及真实货币、充值或兑换。

## 管理员

在部署环境设置与房间密码不同的 `ADMIN_PASSWORD`。进入页选择“管理员”并输入该密码后，可清理当前牌局的玩家、观战者、筹码和座位信息；此操作会使其他已连接用户返回入口。
